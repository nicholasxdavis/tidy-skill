# Tidy Repo Skill

Keep a repository organized, findable, and professionally clean. Split oversized files, refactor structure safely, remove dead clutter and AI-generated text or code, and raise readability without changing behavior by accident[cite: 1].

## Overview

This skill focuses strictly on structure, clarity, and hygiene. It is not a feature dump or a drive-by rewrite of product behavior. It draws from repository cleanup patterns and pragmatic incremental refactoring[cite: 1].

## Installation

Add this skill folder to your agent configuration directory or reference it directly in your workspace instructions.

## When to Use

* Running a general repository cleanup or organization pass
* Dealing with sprawling, duplicated, or hard-to-navigate files and folders
* Splitting oversized god files or extracting discrete modules
* Removing AI-generated fluff, hyperbolic documentation, or session logs before publishing
* Performing pre-ship polish before open source handoff
